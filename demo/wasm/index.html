intl-ai

Browser demo: fill and check a locale file without leaving the page. The wasm bundle runs the same flatten, prompt, parse, and check code as the CLI; your file is never uploaded anywhere except to the configured provider endpoint.

1. Source locale

Drop a locale file (en.json, en.yaml) or paste below

2. Target locale (optional existing file)

Drop an existing target file, or leave empty to fill everything

3. Provider

The default gateway only answers browsers served from an *.illo.fyi origin (CORS). For local development, point the base URL at your own OpenAI-compatible endpoint; an API key is only sent when the field is filled, since api.illo.fyi does not allow the Authorization header cross-origin.
