# intl-ai

AI i18n translation at build time. Zero runtime, any bundler, any model.

[Get started](/guide/getting-started/) · [GitHub](https://github.com/sigilco/intl-ai) · [Sponsor](https://buy.polar.sh/polar_cl_Mv1gdlG7bw3I70EC9IHtfeSHJj4PEKvA7JAUz23CFhj)

## Why intl-ai

- **Any bundler**: Vite, Webpack, Rollup, esbuild, Rspack, Rolldown, Farm, and Next.js. One plugin, every build tool.
- **Any model**: OpenAI, Anthropic, Ollama, or any OpenAI-compatible API. Configure once, translate everywhere.
- **Zero runtime**: All translation happens at build time. No AI SDK in production, no latency, no vendor lock-in.
- **Cross-platform**: Native Expo, Flutter, SwiftUI, and .NET integrations. Ship translations into any mobile or desktop build.
